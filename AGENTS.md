# Правила работы с репозиторием

1. Перед изменением кода сначала обсудить с пользователем предлагаемое решение.
2. Не редактировать файлы, пока пользователь явно не подтвердит выбранное решение.
3. После подтверждения внести изменения и выполнить подходящие проверки.
4. Не создавать коммит сразу после реализации: сначала дождаться проверки пользователем.
5. Когда пользователь сообщает, что всё работает, самостоятельно создать Git-коммит без дополнительной просьбы.
6. Отправлять коммиты в remote только по явной просьбе пользователя.
7. Не включать в коммит посторонние изменения, не относящиеся к проверенной задаче.
8. При изменении команд, зависимостей, версий инструментов, структуры тестов, способов запуска или поддерживаемых платформ обновлять README.md в той же задаче.
